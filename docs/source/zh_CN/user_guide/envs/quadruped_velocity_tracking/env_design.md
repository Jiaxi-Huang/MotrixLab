# 任务环境设计

`QuadrupedWalkTask` 将机体坐标系下的平面线速度 $v_x$、$v_y$ 和偏航角速度 $\omega_z$ 跟踪定义为
机器人无关的任务。共享环境负责 actor/critic 观察、关节位置残差控制、四脚接触与对角小跑相位、奖励、reset
和终止；具体机器人通过 `QuadrupedWalkEnvCfg.scene` 中的 `QuadrupedRobotCfg` 提供模型、默认姿态、基座 link
和四只脚的接触 geom，任务配置再提供传感器名称与数值参数。

## 动作空间

令 $A$ 为 actuator 数量。动作空间是 $A$ 维连续 `Box`，每一维对应一个以关节为目标的 actuator。策略输出
表示相对于 `key_pose_name` 所选关键姿态的关节位置残差：

$$
q_{target}=q_{key\_pose}+action\_scale\cdot a
$$

每个动作维度的上下界分别根据 actuator 控制范围计算：

$$
a_{min,i}=\frac{q_{min,i}-q_{key\_pose,i}}{action\_scale},\qquad
a_{max,i}=\frac{q_{max,i}-q_{key\_pose,i}}{action\_scale}
$$

因此动作边界通常是非对称的，并且不同关节可以有不同范围。`simulate_action_latency=false` 时当前动作立即用于
控制；设为 `true` 时，物理控制使用上一控制步动作，但观察中的动作项仍是当前策略输出。

## 观察空间

环境使用非对称 actor-critic 观察。令 $F$ 为脚的数量；四足配置固定按前左、前右、后左、后右顺序提供
$F=4$ 只脚。

| 观察项                     | Actor | Critic | 说明                                       |
| -------------------------- | ----: | -----: | ------------------------------------------ |
| 机体局部角速度             |     3 |      3 | 由 `sensor.gyro` 读取，可加入均匀噪声      |
| 负 Up-vector               |     3 |      3 | `sensor.upvector` 的相反数，可加入均匀噪声 |
| 关节位置相对关键姿态的偏差 |   $A$ |    $A$ | 可加入均匀噪声                             |
| 关节速度                   |   $A$ |    $A$ | 可加入均匀噪声                             |
| 当前动作                   |   $A$ |    $A$ | 当前策略输出                               |
| 速度命令                   |     3 |      3 | $v_x$、$v_y$、$\omega_z$                   |
| 四脚步态相位               |   $F$ |    $F$ | 每只脚一个 $[0,1)$ 相位值                  |
| 机体局部线速度             |     — |      3 | Critic 特权信息，可加入均匀噪声            |

Actor 维度为 $9+3A+F$，Critic 额外增加 3 维。内置机器人均有 12 个 actuator 和 4 只脚，因此两者
分别为 49 维和 52 维。

`noise_config` 对陀螺仪、Up-vector、关节位置、关节速度和 critic 的局部线速度分别加入零均值均匀噪声。
Actor 与 Critic 共享的字段使用同一份带噪值；当前实现没有额外的观察缩放或历史堆叠。

## 对角小跑参考

环境用 `gait_frequency` 推进一个归一化周期。默认 `2 Hz` 时，每个控制步按
`ctrl_dt * gait_frequency` 增加相位。`trot_pairs=((0, 3), (1, 2))` 将前左脚与后右脚、前右脚与后左脚
组成两组；同组同步，两组相差半个周期。相位小于 `0.6` 表示期望支撑，大于等于 `0.6` 表示期望摆动。

当速度命令的欧氏范数小于 `commands.velocity.standing_threshold` 时，共享相位和各足相位保持为 0。此时所有脚
使用支撑参考，不会被迫继续对角小跑周期，从而为显式零命令提供一致的站立目标。

四个接触 sensor 判断脚是否着地，四个足端位置 sensor 提供机体参考系中的足端位置。接触匹配、摆动离地高度和
摆动期误触地奖励都使用这些状态。

## 奖励设计

| 奖励项               | 计算方式                                               | 设计目的                   |
| -------------------- | ------------------------------------------------------ | -------------------------- |
| `tracking_lin_vel`   | 对命令与实际机体局部 XY 线速度的平方误差应用指数核     | 跟踪前后与横向速度命令     |
| `tracking_ang_vel`   | 对命令与实际偏航角速度的平方误差应用指数核             | 跟踪转向命令               |
| `lin_vel_z`          | 计算机体局部 z 轴线速度的平方                          | 抑制不必要的竖直运动       |
| `ang_vel_xy`         | 计算 roll、pitch 角速度的平方和                        | 抑制机体快速晃动           |
| `base_height`        | 计算机体相对局部地面高度与目标高度的平方误差           | 维持适合机器人的机体高度   |
| `action_rate`        | 计算相邻控制步动作差的平方和                           | 减少动作突变和关节抖动     |
| `similar_to_default` | 计算关节角偏离关键姿态的绝对值之和                     | 避免步态远离稳定姿态       |
| `contact`            | 计算实际接触状态与支撑/摆动参考一致的脚所占比例        | 形成对角小跑的落足节奏     |
| `swing_feet_z`       | 在摆动且未接触时，对足端高度误差应用指数核并按脚数平均 | 鼓励摆动脚达到目标离地高度 |
| `swing_contact`      | 计算摆动期仍接触地面的脚所占比例                       | 惩罚拖脚和过早落足         |

每个原始项先乘以 `RewardScales` 中的权重；负权重将非负度量转为惩罚。`state.reward_terms` 保存这些尚未
乘控制步长的加权项，所有项求和后再乘 `ctrl_dt`，得到返回给训练算法的单步奖励。当前环境没有奖励课程。

粗糙地形上，`base_height` 使用机器人当前位置的地形高度作为零点。`swing_feet_z` 的足端位置来自机体参考系，
目标 z 为 `target_foot_height - base_height_target`，因此不会随机器人世界坐标高度整体平移。

## 终止条件

| 类型     | 状态         | 条件                               | 含义                               |
| -------- | ------------ | ---------------------------------- | ---------------------------------- |
| 倾倒终止 | `terminated` | Up-vector 的 z 分量不大于 `0.5`    | 机器人已经明显侧翻或倒置           |
| 时间截断 | `truncated`  | 回合时长达到 `max_episode_seconds` | 正常达到时间上限，不表示机器人跌倒 |

脚、躯干或地面接触本身不会触发 failure termination；足部接触仅参与步态奖励。

## 重置逻辑

重置时，环境先恢复模型状态，将 floating base 放到 `initial_base_position`，把 actuator 关节恢复到
`key_pose_name` 指定的姿态，并清零所有速度、当前动作和上一动作。随后设置 actuator 控制目标、刷新运动学、读取
四脚接触与位置、采样速度命令，并把共享相位和四脚相位初始化为 0。

| 随机化项      | 采样方式                                                                                                             | 生效时机                                 | 作用                           |
| ------------- | -------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- | ------------------------------ |
| 速度命令      | 各轴在 `commands.velocity.lower` 与 `commands.velocity.upper` 之间独立采样，再以 `standing_probability` 的概率改为零 | 每次 reset；回合内不重新采样             | 覆盖平移、转向和显式站立目标   |
| 初始 x/y 位置 | 当 `spawn_xy_range > 0` 时，在 `[-spawn_xy_range, spawn_xy_range]` 内独立均匀采样                                    | 每次 reset；z 根据出生点附近最高地形抬高 | 覆盖不同地形区域并避免穿入地面 |
| 观察噪声      | 各分量加入 `[-1,1] * noise_config.level * scale_*` 均匀噪声                                                          | 每次构造观察时                           | 提高策略对传感器误差的鲁棒性   |

这些是任务命令、初始状态和观察随机化。当前环境不会随机化质量、惯量、摩擦、执行器参数或控制延迟，因此没有物理域
随机化；`simulate_action_latency` 是每份配置固定选择的控制模式，不会在回合间随机变化。
