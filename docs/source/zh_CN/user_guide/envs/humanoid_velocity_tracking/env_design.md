# 任务环境设计

`HumanoidVelocityTrackingEnv` 将机体坐标系下的平面线速度 $v_x$、$v_y$ 和偏航角速度 $\omega_z$ 跟踪定义为
机器人无关的任务。共享环境负责构造 actor/critic 观察、将策略动作转换为关节位置目标、维护双脚步态、计算奖励与惩罚课程，
并处理 reset 和终止；实现中不包含具体机器人名称，也不假设固定的关节数量。

具体机器人通过 `HumanoidVelocityTrackingEnvCfg` 提供模型语义和数值参数：`scene` 中的 `HumanoidRobotCfg` 指定机器人模型、
默认姿态、基座和左右脚 link，任务侧 `asset` 指定脚底 site、地面 geom 和终止接触规则，其余配置用于调整动作缩放、奖励权重
和出生范围。这样，同一套任务逻辑可以直接复用于不同尺寸和关节结构的人形机器人。

## 动作空间

令 $A$ 为 position actuator 数量，动作空间是 $A$ 维连续 `Box`，每个维度对应一个 actuator。策略输出相对于默认站立
姿态的关节位置残差，环境按下式计算 position actuator 的目标关节角：

$$
q_{target}=q_{default}+action\_scale\cdot a
$$

`control_config.action_scale` 决定单位动作对应的目标关节角变化。每个动作维度采用以零为中心的对称边界：

$$
b_i=\frac{\max\left(\left|q_{min,i}-q_{default,i}\right|,
\left|q_{max,i}-q_{default,i}\right|\right)}{action\_scale},
\qquad a_i\in[-b_i,b_i]
$$

其中 $q_{min,i}$ 和 $q_{max,i}$ 来自对应 position actuator 直接声明或从目标关节继承的 `ctrl_range`。因此，不同关节的
动作边界可以不同，且默认姿态不需要位于控制范围的中点。

## 观察空间

环境使用非对称 actor-critic 观察。令 $J$ 为机器人关节自由度数量，$A$ 为 actuator 数量，则组成如下：

| 观察项               | Actor | Critic | 说明                         |
| -------------------- | ----: | -----: | ---------------------------- |
| 机体局部线速度       |     — |      3 | Critic 特权信息              |
| 机体局部角速度       |     3 |      3 | 按配置缩放                   |
| 投影重力             |     3 |      3 | 重力方向在机体坐标系中的投影 |
| 速度命令             |     3 |      3 | $v_x$、$v_y$、$\omega_z$     |
| 关节位置偏差         |   $J$ |    $J$ | Actor 侧加入均匀噪声         |
| 关节速度             |   $J$ |    $J$ | Actor 侧加入均匀噪声         |
| 当前动作             |   $A$ |    $A$ | 当前策略输出                 |
| 双脚相位的正弦与余弦 |     4 |      4 | 两只脚各一组相位编码         |

当每个关节都有一个 actuator 时，Actor 维度为 $13+3J$，Critic 维度为 $16+3J$；将机器人的实际关节数代入 $J$ 即可
得到对应的观察维度。

## 奖励设计

环境按照 `gait.period` 推进双脚相位，并根据 `gait.swing_height` 生成脚底期望高度。站立命令会固定相位，不要求脚部
摆动。高度场版本会在每一步采样脚底位置处的地形高度，因此脚部离地奖励仍以局部地面为参考。

| 奖励项                  | 计算方式                                             | 设计目的                                               |
| ----------------------- | ---------------------------------------------------- | ------------------------------------------------------ |
| `tracking_lin_vel`      | 对命令与实际机体局部平面线速度的平方误差应用指数核   | 准确跟踪前后和横向速度命令                             |
| `tracking_ang_vel`      | 对命令与实际偏航角速度的平方误差应用指数核           | 准确响应转向命令                                       |
| `penalty_ang_vel_xy`    | 计算机体 roll、pitch 角速度的平方和                  | 抑制行走时的快速晃动                                   |
| `penalty_orientation`   | 计算投影重力在机体水平面内分量的平方和               | 鼓励躯干保持直立                                       |
| `penalty_action_rate`   | 计算相邻两个控制周期动作差的平方和                   | 减少动作突变和关节抖动                                 |
| `feet_phase`            | 对双脚实际离地高度与相位期望高度的平方误差应用指数核 | 形成与步态相位一致的支撑和摆动节奏                     |
| `pose`                  | 按关节权重计算当前关节角偏离默认姿态的平方和         | 约束躯干、手臂等部位，同时为主要行走关节保留运动自由度 |
| `penalty_close_feet_xy` | 检查机体朝向坐标系下的双脚横向距离是否小于阈值       | 避免双脚过近或交叉                                     |
| `penalty_feet_ori`      | 衡量重力方向在双脚局部水平面内的分量                 | 鼓励脚底姿态接近水平                                   |
| `alive`                 | 每步返回固定值                                       | 使提前跌倒减少可获得的累计回报                         |

每个原始项先乘以 `RewardScales` 中的权重，再乘以控制步长；`penalty_*` 和 `pose` 等约束项通过负权重成为惩罚。
课程指定的惩罚项还会根据已结束回合的平均长度乘以当前 `penalty_scale`。该缩放记录在
`state.metrics["penalty_scale"]`，最终的各加权项记录在 `state.reward_terms`。

## 终止条件

| 类型     | 状态         | 条件                                                                  | 含义                                   |
| -------- | ------------ | --------------------------------------------------------------------- | -------------------------------------- |
| 接触终止 | `terminated` | `asset.terminate_contact_geom_names` 列出的任一机器人碰撞体与地面接触 | 通常用于检测骨盆、躯干等非足部部位接地 |
| 时间截断 | `truncated`  | 回合时长达到 `max_episode_seconds`                                    | 正常达到时间上限，不表示机器人跌倒     |

## 重置逻辑

重置时，环境将关节恢复到配置指定的默认姿态，将关节和基座速度以及当前、上一时刻动作清零，然后重新计算运动学状态。
起伏地形配置还会根据出生点周围的高度场调整基座高度。

环境中的随机化项如下：

| 随机化项           | 采样方式                                                                                            | 生效时机                                       | 作用                           |
| ------------------ | --------------------------------------------------------------------------------------------------- | ---------------------------------------------- | ------------------------------ |
| 速度命令           | 在 `commands.vel_limit` 给出的三个维度范围内均匀采样，并以 `commands.stand_prob` 的概率改为全零命令 | 重置时及每隔 `commands.resampling_time`        | 覆盖不同平移、转向和站立任务   |
| 初始步态相位       | 一只脚的相位偏移在 $[-\pi,\pi]$ 内均匀采样，另一只脚与其相差半个周期                                | 重置时                                         | 避免所有环境从固定步态时刻开始 |
| 起伏地形出生位置   | 当 `spawn_xy_range > 0` 时，X、Y 坐标分别在 `[-spawn_xy_range, spawn_xy_range]` 内均匀采样          | 重置时，并根据出生点周围的局部最高地面抬高基座 | 覆盖不同地形区域               |
| Actor 关节观察噪声 | 在缩放后的关节位置和速度上分别叠加由 `noise_dof_pos`、`noise_dof_vel` 控制的均匀噪声                | 每次构造观察时；Critic 观察不加噪声            | 提高策略对观测误差的鲁棒性     |

这些条目属于任务命令、初始状态和观察随机化。当前环境不会随机化质量、摩擦、PD 增益等物理参数，因此没有额外的物理
域随机化项。
